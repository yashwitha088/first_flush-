# FirstFlush India hackathon demo script

## Opening

“Rain is coming, but environmental teams cannot inspect every urban drain first.”

## Dashboard

Show:

- weather mode;
- forecast window;
- dry-period value;
- monitored locations;
- very-high-risk locations;
- pending actions.

## Prioritization

Select the highest-ranked location and explain:

- dry-period accumulation;
- rainfall;
- paved exposure;
- traffic;
- construction;
- waste/blockage evidence;
- water-body proximity;
- confidence;
- evidence freshness.

## Field observation

Submit:

- Blocked drain;
- high severity;
- blockage level;
- optional photo;
- field notes.

Show that:

- the observation becomes pending verification;
- the dashboard refreshes;
- the risk explanation reflects current application data.

## Verification and action

Verify the observation, then create an action:

- Inspect;
- Clean;
- Temporary screen/diversion;
- Collect water sample;
- Monitor.

Update the action status and show the action queue change.
